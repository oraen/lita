# 慢手耳鼻喉测试 · 小红书小工具

离线入口：`dist/index.html`。上传包：`lita-xhs.zip`（入口在 ZIP 根目录）。

## 构建

在项目根目录执行：

打包需要 Python 3（仅使用标准库，可通过 `PYTHON` 环境变量指定程序路径）。打包器统一使用 `/` 路径，并重新读取 ZIP 检查路径、入口和文件内容，避免 Windows 压缩工具产生不兼容的分隔符。

```sh
npm install
npm run build:xhs
```

构建直接复用项目的页面、样式、测试算法、级别规则和报告绘图；`xhs` 中仅维护容器适配。图片从 `source/psychology/*.jpg` 打包，年龄仍在运行时从原始文件名解析。新增图片、修改文件名或主项目功能后，重新构建小工具即可同步。

`dist` 是完整离线网页，不需要运行 Node 服务。将 ZIP 上传小红书小工具调试器或导入模拟器；普通浏览器可查看页面，保存相册需要小红书注入的原生接口。

## 功能

- 听觉：设备发声、频率滑条、专业范围测试、历史和诊断详情。
- 发声：麦克风检测、音调范围测试、曲线、历史和诊断详情。
- 心理年龄：图片双列初选 12 张、精选 6 张、A 组 10 轮与 B 组 5 轮；采用当前分组权重，总分除以 35，保留两位小数。
- 视觉：四向 E、1～100 L、0.5 精度、三次连续正确/两次连续错误、超出范围显示 >100 L、历史和详情。
- 办理中心：三种证书、八种主体色、默认粉色、头像与昵称缓存、最后一次成绩、手动修改伪造证明、完整方形报告和印章。
- 首页开发者名片。

## 容器适配

- 所有脚本、图片和 Pitchy 依赖打入 ZIP；经典 IIFE 脚本，构建目标 ES2017 / Chrome 61，无模块加载和网络请求。
- 保存报告使用 `writeTempFile({data: 完整 data URI})` → `saveImageToPhotosAlbum({filePath})`，保留权限失败提示及重试；不使用浏览器下载、系统分享或长按保存。
- 首页名片仅展示头像与作者信息，无点击交互和跳转。
- 补充实际需要的旧内核运行时 API、Flex 间距、Grid 间距、图片比例、安全区和焦点样式回退。进入后台停止声音和麦克风。
- 小工具本地数据与网页版本各自隔离，已有网页历史不会自动迁移。

## 验证

```sh
npm test
node xhs/smoke.mjs
```

`smoke.mjs` 使用本机 Chrome（可通过 `CHROME_PATH` 指定路径），在临时目录中验证离线图片、五个入口、听觉播放控制、模拟麦克风权限和释放、完整心理与视觉流程、历史卡片、头像缓存、八种颜色报告、原生保存参数和错误恢复。相册桥接及麦克风输入为模拟；不向小红书发送数据。

每次构建会运行 `verify.mjs` 静态检查，并用 skill 提供的 `audit_artifact.mjs` 审计目录和 ZIP 体积。首次版本浏览器集成检查及 52 项共享测试通过。

**尚未实测**：小红书真机麦克风授权与频率准确性、扬声器表现、相册权限与保存、Chrome 61 CSS 兼容性、真机性能。模拟接口通过不代表真机原生能力已验收。
